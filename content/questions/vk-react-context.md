## Короткий ответ

Context — механизм React для передачи данных через дерево компонентов без явной прокидки пропсов на каждом уровне. Создаётся через `createContext(defaultValue)`, значение публикует `<Context.Provider value={...}>`, читают через `useContext(Context)`. Подходит для редко меняющихся «глобальных» данных: тема, локаль, текущий пользователь, конфигурация.

## Контекст

Context решает проблему prop drilling, но это не замена стейт-менеджеру: при изменении `value` перерендериваются все потребители контекста, поэтому часто меняющееся состояние в один большой контекст класть не стоит.

## Как строить ответ

### API

- `const ThemeContext = createContext('light')` — значение по умолчанию используется, если провайдера нет.
- `<ThemeContext.Provider value={theme}>` — публикация значения поддереву.
- `const theme = useContext(ThemeContext)` — чтение ближайшего провайдера сверху.
- В React 19 провайдером может быть сам `<ThemeContext value={...}>`.

### Подводные камни

- Ре-рендер всех потребителей при новом `value` (сравнение по `Object.is`).
- Объект `{ user, setUser }` в `value` надо мемоизировать (`useMemo`), иначе каждый рендер — новая ссылка.
- Дробить контексты по доменам (тема отдельно, юзер отдельно), чтобы подписки были точечными.

### Когда что использовать

- Context — тема, i18n, auth, DI сервисов.
- Стейт-менеджер — часто меняющееся разделяемое состояние.
- Композиция/children — часто решает «дреллинг» без контекста вообще.

## Пример ответа

«Context — способ пробросить данные вниз по дереву минуя промежуточные компоненты. Создаю `createContext`, оборачиваю нужное поддерево в Provider, читаю через `useContext`. Использую для стабильных вещей вроде темы и текущего пользователя. Слежу за двумя вещами: мемоизирую `value`, и не кладу часто меняющийся стейт в один контекст — иначе каждое обновление рендерит всех подписчиков.»

## Частые ошибки

- Передавать немемоизированный объект в `value`.
- Считать Context полноценным стейт-менеджером.
- Один гигантский AppContext на всё приложение.
- Забывать, что значение по умолчанию работает только без провайдера.
