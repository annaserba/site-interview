## Короткий ответ

Три метода: call(thisArg, ...args) — вызов сразу, аргументы списком; apply(thisArg, argsArray) — вызов сразу, аргументы массивом; bind(thisArg, ...args) — не вызывает, а возвращает новую функцию с навсегда привязанным this, поддерживает частичное применение. Плюс стрелочные функции — лексический this без подмены.

## Контекст

Продолжение вопроса про this: нужен точный контракт трёх методов и понимание жёсткой привязки.

## Как строить ответ

### call и apply

Мгновенный вызов с заданным this. Разница только в передаче аргументов: call — через запятую, apply — массивом. Мнемоника: Apply — Array.

### bind

Возвращает обёртку с жёстко привязанным this — вызов откладывается. Привязку нельзя переопределить последующими call/bind. Поддерживает каррирование: bind(obj, 1, 2) фиксирует первые аргументы.

### Жёсткая привязка

Порядок приоритета this: new > явная привязка (bind/call/apply) > вызов как метод > дефолт (глобальный объект или undefined в strict mode).

### Практика

bind — колбэки и обработчики событий; call/apply — заимствование методов; в современном коде часто заменяется стрелочными функциями.

## Пример ответа

Способа три. fn.call(obj, a, b) и fn.apply(obj, [a, b]) вызывают функцию немедленно с указанным this; отличаются только формой аргументов — call принимает список, apply — массив. fn.bind(obj) вызова не производит: возвращает новую функцию, у которой this навсегда зафиксирован, — это жёсткая привязка, её не переопределить ни повторным bind, ни call. bind удобен для колбэков: передал метод в обработчик и не потерял контекст; плюс он умеет частичное применение аргументов — bind(obj, first) вернёт функцию с предзаданным первым аргументом. Стоит помнить приоритеты this: new сильнее явной привязки, она сильнее вызова через точку. В современном коде часть случаев закрывается стрелочными функциями с лексическим this.

## Частые ошибки

- Путать: bind вызывает функцию (нет — возвращает новую)
- Думать, что this после bind можно перебить
- Потерять контекст, передав метод объекта по ссылке
- Использовать apply там, где нужен спред-вызов fn(...args)
