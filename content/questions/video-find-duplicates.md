## Короткий ответ

Задача: из массива вернуть элементы, встречающиеся более одного раза. Классическое решение за O(n) — один проход с `Set`: кладём элемент, и если он уже был — это дубликат (второй Set собирает ответ, чтобы не повторяться). Наивное решение — вложенный цикл за O(n²): для каждого элемента ищем совпадение среди остальных. Уточнения, которые стоит задать: вернуть сами дубликаты или их количество? уникальны ли значения в ответе? какие типы данных (примитивы или объекты)?

## Контекст

Простая лайвкодинг-задача на разогрев. Оценивают не только результат, но и процесс: уточнение требований, проговаривание сложности, выбор структуры данных, аккуратность кода.

## Как строить ответ

### Решение за O(n)

- Один проход, Set «уже видели» + Set «дубликаты».
- Сложность: O(n) по времени, O(n) по памяти.

### Наивное решение

- Вложенный цикл или `filter` + `indexOf` — O(n²), подходит только для крошечных массивов.

### Что проговорить вслух

- Уточнения: формат ответа, типы элементов, порядок.
- Объекты: Set сравнивает по ссылке — для объектов нужен ключ/сериализация.
- Альтернатива: подсчёт через Map, если нужны количества.

## Код из интервью

```javascript
// O(n): вернуть уникальные дубликаты
function findDuplicates(arr) {
  const seen = new Set()
  const duplicates = new Set()
  for (const item of arr) {
    if (seen.has(item)) duplicates.add(item)
    else seen.add(item)
  }
  return [...duplicates]
}

findDuplicates([1, 2, 3, 2, 4, 3, 3]) // [2, 3]

// Наивное O(n^2) — для сравнения
function findDuplicatesSlow(arr) {
  return arr.filter((item, i) =>
    arr.indexOf(item) !== i && arr.indexOf(item) === i || false
  )
}
```

## Пример ответа

«Сначала уточню: вернуть сами повторяющиеся значения без повторов, элементы — примитивы. Тогда один проход с двумя Set: seen для встреченных, duplicates для ответа — O(n) по времени и памяти. Наивный вариант — вложенный цикл за O(n²), его писать не буду, но назову. Если элементы — объекты, Set по ссылке не поможет: попрошу ключ уникальности или сериализую.»

## Частые ошибки

- Сразу писать код без уточняющих вопросов.
- Вернуть дубликаты с повторами (`[2, 3, 3]` вместо `[2, 3]`).
- Забыть проговорить сложность.
- Не упомянуть кейс с объектами.

## Дополнительные вопросы

- Как посчитать количество вхождений каждого элемента?
- Что изменится, если элементы — объекты?
- Можно ли решить за O(1) по памяти? (сортировка, но O(n log n))
- Как найти единственный неповторяющийся элемент? (XOR-трюк)
