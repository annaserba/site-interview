## Короткий ответ

Основные виды: function declaration (поднимается целиком), function expression (поднимается только переменная), стрелочные функции (нет своего this, arguments, prototype, нельзя как конструктор), методы объектов и классов, конструкторы, генераторы и async-функции. Ключевые различия — hoisting, this, arguments, new.

## Контекст

Классическая разминка: проверяют фундамент — hoisting, контекст и синтаксические формы.

## Как строить ответ

### Declaration vs Expression

Function declaration поднимается целиком — можно вызвать до объявления. Function expression (const f = function(){}) поднимается как переменная: до инициализации — TDZ для let/const.

### Стрелочные функции

Нет своего this — берут из окружающего лексического контекста; нет arguments, super, prototype; нельзя вызвать через new. Идеальны для колбэков, плохи как методы объектов.

### Методы и конструкторы

Метод объекта/класса имеет this из объекта вызова. Функция-конструктор вызывается с new и создаёт объект с прототипом. ES5-класс — это функция-конструктор плюс prototype.

### Особые формы

IIFE — изоляция области видимости; генераторы function* — ленивая итерация; async-функции — всегда возвращают промис.

## Пример ответа

Функции в JS различаются по форме объявления и поведению. Function declaration поднимается целиком, её можно вызвать выше по коду; function expression живёт как переменная, и до инициализации вызов упадёт — для let/const это TDZ. Стрелочные функции короче и главное — не имеют своего this: контекст берётся лексически снаружи, поэтому они удобны в колбэках, но не подходят методам объекта; у них также нет arguments и prototype, и их нельзя вызывать через new. Методы объектов и классов получают this от объекта вызова. Отдельные формы: функции-конструкторы для new, IIFE для изоляции, генераторы function* для ленивых последовательностей и async-функции, которые всегда возвращают промис. Выбираю форму по требованиям к this и hoisting.

## Частые ошибки

- Использовать стрелочную функцию как метод объекта и терять this
- Ждать hoisting от function expression
- Вызывать стрелочную функцию через new
- Искать arguments внутри стрелочной функции
