## Короткий ответ

Кросс-браузерность — одинаковая работа и вид во всех целевых браузерах. Инструменты: автопрефиксер в сборке, проверка поддержки через caniuse, @supports для прогрессивного улучшения, фолбэки (flex → grid, старые синтаксисы градиентов), reset/normalize, полифилы для JS API и тестовая матрица реальных браузеров.

## Контекст

Проверяют практический опыт: не «знаю слово», а конвейер — от выбора фич до тестирования.

## Как строить ответ

### Префиксы и сборка

-webkit-, -moz- добавляет autoprefixer по browserslist — руками не пишем. Browserslist задаёт целевые браузеры проекта.

### Проверка поддержки

caniuse перед использованием фичи. @supports — ветвление в CSS: фолбэк по умолчанию, улучшение при поддержке. Новые фичи: :has(), container queries, subgrid — с осторожностью.

### Слои совместимости

Reset/normalize убирает различия дефолтов; фолбэки: сначала простое правило, потом современное — каскад сам выберет последнее поддерживаемое; для JS — полифилы и core-js.

### Тестирование

Матрица целевых браузеров, реальные устройства или BrowserStack, визуальные регрессионные тесты; Safari — главный источник сюрпризов.

## Пример ответа

Кросс-браузерность — это когда интерфейс одинаково выглядит и работает во всех браузерах из нашей матрицы поддержки. Практический конвейер такой: целевые браузеры фиксируем в browserslist, autoprefixer в сборке сам расставляет вендорные префиксы. Перед использованием новой фичи проверяю caniuse; если поддержка неполная — @supports: базовый вариант для всех, улучшенный для поддерживающих, например сначала flexbox-раскладка, поверх — grid. Каскад помогает бесплатно: пишем старое правило, следом новое — неподдерживаемое просто игнорируется. Различия дефолтных стилей убирает normalize.css, для JS-API — полифилы. И обязательное тестирование: реальные устройства или BrowserStack, потому что Safari регулярно ломает то, что «работает в Chrome».

## Частые ошибки

- Писать префиксы руками вместо autoprefixer
- Использовать фичу без фолбэка, если она есть в Chrome
- Тестировать только в Chrome до самого релиза
- Сбрасывать стили через * { margin: 0 } вместо normalize
